# Anonymous Conveyor Scan Logs — observation-only source data

These four CSV parts contain the actual **4,000 shifts and 640,000 scans** in the Conveyor Route Recovery challenge's frozen corpus. They are the public-feature version of that corpus: each row has `case_id,bank0,bank1,bank2,bank3`, and each bank contains 40 scan objects with `scan_id,time,lane,channels`. The four parts have 1,000 rows each and are sorted by opaque `case_id` only for stable publication. Their union is exactly the 3,000 training-feature and 1,000 evaluation-feature rows produced by `prepare.py`; see `SAFE_DATA_MANIFEST.json` for source and part SHA-256 hashes.

The source data are an original creator-owned simulation. The registered creator-side `shifts.csv` additionally contains parcel identity, which supplies hidden correspondence targets. That identity, the private answers and the master generation key are **not published** here. The public observation data contain no target mappings, predictions or train/test split labels. The full six-file raw creator upload is provided separately to the platform, where `prepare.py` validates it and creates public/private outputs.

The source generator, raw provenance, release metadata and CC0 data notice are in `raw/` in this same repository. The original simulated data and this observation-only publication are **CC0 1.0**; the generator code is **MIT**. No third-party dataset or personal data was used.
